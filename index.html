Quick Start (for 20-year-olds)
Everything you need in 60 seconds: build trust, avoid spam, and ship emails safely.

1) Set your sender

Open the Access tab, log in, and confirm your sender address. Keep it real: yourname@yourdomain.com.

2) Single vs Recurring

Use Single Send for one-offs. Use Compose → Recurring to drip updates (daily/weekly). Space sends 5–10 mins apart.

3) Files & Limits

Add up to 3 files per email. Large? Zip first. Use Folder Pairs to auto-pick new files on certain weekdays.

4) Safety

Always test-send to yourself. Check the checksum file before installing updates. Don’t send creds or secrets.

Workflow Guide

Quick map of how actions, schedules, folders, and recipients relate. Use these patterns to plan automations and avoid collisions.

One → One

Single send or one-off schedule to one recipient. Best for approvals and sign-offs.

One → Many

One schedule triggers multiple recipients. Keep batch size low to avoid throttling; attach up to 3 files.

Many → One

Multiple folder pairs feed a single recipient (e.g., all daily reports to ops@). Use folder days to prevent overlap.

Many → Many

Multiple schedules, folders, and recipients. Use naming + day filters; stagger intervals (e.g., 10m offsets) to spread load.

Checks & Best Practices

  • Name schedules with recipient + purpose (e.g., “Ops-daily-status”).
  • Offset start times by 5–10 minutes when multiple schedules share a folder.
  • Keep a single owner per folder pair; avoid many schedules writing to same destination.
  • Use checksum tab in releases to verify downloads before install.
  • Run a dry send to yourself after any template or folder change.
